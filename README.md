# Shopilo — E-Commerce Web Application

A responsive e-commerce web application built with React, featuring 
multi-page navigation, product browsing, cart management, wishlist, 
and checkout flow. No backend — all data is served from the DummyJSON API.

**Live Demo:** https://shopilooo.netlify.app

---

## Tech Stack

- React 18 + Vite
- React Router v6
- Context API — global cart and wishlist state
- TailwindCSS — responsive design
- DummyJSON API — free product data, no API key required

---

## Features

- Product browsing by category
- Product detail pages
- Search functionality
- Add to cart and wishlist
- Responsive design across all screen sizes

---

## Getting Started

```bash
npm install
npm run dev
```

---

## Project Structure

```
src/
├── components/    # Reusable UI components
├── pages/         # Full page views
├── context/       # Global state (cart, wishlist)
├── hooks/         # Custom hooks
└── utils/         # Helper functions
```
